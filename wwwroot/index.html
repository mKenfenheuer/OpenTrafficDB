    How it works

    1

    Register

    Create a free account with your email and password. Verify your email to activate.

    2

    Create an API key

    Log in and go to your profile to create one or more named API keys (e.g. per device).

    3

    Get a JWT

    Exchange your API key for a short-lived JWT. The token is bound to your IP for security.

    4

    Submit & export

    POST GPS observations. After 100 valid ones you're a Contributor. Download Valhalla traffic CSV any time.

    Privacy first

    IPs and emails are SHA-256 hashed. Raw values are never stored. Observations are anonymized.

    Live traffic

    Query real-time speeds within any bounding box. Observations from the last 60 minutes.

    Valhalla export

    2016-bucket predicted traffic CSV, ready for valhalla_add_predicted_traffic.

    Contributor rank

    Submit 100+ valid observations to be auto-promoted to Contributor with higher rate limits.

    Server-side matching

    Just submit lat/lon/speed — map-matching to Valhalla edges happens automatically.

    Batch ingest

    Submit up to 100 observations in a single API call. Rate limits are per-IP and per-key.

    Quick start (machine access)
    # 1. Register at /register.html, verify email, then create an API key at /profile.html # 2. Get a JWT (bound to your current IP) curl -X POST /api/v1/auth/token \ -H 'Content-Type: application/json' \ -d '{"apiKey":"<your-api-key>"}' # 3. Submit an observation curl -X POST /api/v1/speed \ -H 'Authorization: Bearer <token>' \ -H 'Content-Type: application/json' \ -d '{"latitude":48.8566,"longitude":2.3522,"speedMs":13.9,"tripId":"trip-1","timestamp":"2024-01-01T12:00:00Z"}' # 4. Export predicted traffic CSV for Valhalla curl /api/v1/traffic/predicted/csv \ -H 'Authorization: Bearer <token>' -o traffic.csv valhalla_add_predicted_traffic --config valhalla.json -t traffic.csv
